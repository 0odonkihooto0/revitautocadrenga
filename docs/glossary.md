# Глоссарий

Сокращения и термины, используемые в документах проекта. Читается по требованию.

## Разделы проектной документации

| Сокращение | Расшифровка |
|---|---|
| АР | Архитектурные решения |
| КЖ | Конструкции железобетонные |
| ВК | Внутренние системы водоснабжения и канализации (пилотный раздел проекта) |
| ЭОМ | Электрооборудование и электроосвещение |
| ОВ / ОВиК | Отопление, вентиляция (и кондиционирование) |
| ИОС | «Сведения об инженерном оборудовании…» — раздел ПД по ПП № 87; ИОС2 — водоснабжение, ИОС3 — водоотведение |

## Нормативка и роли

| Сокращение | Расшифровка |
|---|---|
| СП | Свод правил (например, СП 30.13330.2020) |
| СНиП | Строительные нормы и правила (предшественники СП) |
| ГОСТ | Государственный стандарт |
| СПДС | Система проектной документации для строительства |
| ПП № 87 | Постановление Правительства РФ № 87 о составе разделов проектной документации |
| ГИП | Главный инженер проекта (подписывает и несёт ответственность) |
| ТЗ | Техническое задание |
| ТУ | Технические условия (на подключение к сетям) |
| ПЗ | Пояснительная записка |

## Обозначения систем ВК

| Обозначение | Значение |
|---|---|
| В1 | Хозяйственно-питьевой водопровод |
| Т3 | Подающий трубопровод горячего водоснабжения (Т4 — циркуляционный) |
| К1 | Бытовая канализация |
| ГВС | Горячее водоснабжение |
| Ду | Условный диаметр (диаметр условного прохода), например Ду110 |
| Ст | Стояк (например, Ст К1-1) |

## Технологии

| Термин | Значение |
|---|---|
| LLM | Большая языковая модель (Claude и др.) |
| MCP | Model Context Protocol — открытый протокол подключения инструментов к LLM |
| RAG | Retrieval-augmented generation — генерация с поиском по базе знаний |
| BIM | Информационное моделирование зданий |
| IFC | Industry Foundation Classes — открытый формат обмена BIM-моделями |
| MEP | Mechanical, Electrical, Plumbing — инженерные разделы (западный термин) |
| САПР | Система автоматизированного проектирования (Revit, Renga, AutoCAD…) |
| COM | Component Object Model — механизм интеграции Windows (через него открыт API Renga) |
| clash detection | Поиск пересечений (коллизий) элементов модели |
| A* / Дейкстра | Алгоритмы поиска пути на графе (основа трассировщика) |
| human-in-the-loop | Человек в контуре: ИИ готовит, решение принимает инженер |
