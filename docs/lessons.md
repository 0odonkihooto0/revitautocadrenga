# Уроки и грабли

> Append-only журнал: наступили на грабли → записали, чтобы не повторить.
> Формат: «Симптом → Причина → Правило». Новые записи — сверху.

## 2026-07-18 — md-конвертация СП теряет формулы и знаки сравнения

- **Симптом.** На валидации базы модель с полнотекстовым поиском провалила 8 из 30
  вопросов: формулы в md помечены «formula-not-decoded», в «N ≤ 200» пропал знак «≤»
  («N  200») — модель честно пасовала либо угадывала знак (один раз — неверно).
- **Причина.** Конвертер PDF→md не распознаёт формулы-изображения и юникод-символы
  сравнения; полнотекстовый слой в этих местах молча неполон.
- **Правило.** Числа и формулы — только через слой 1 (YAML-правила, сверенные с PDF):
  в norms_mcp есть list_rules/get_rule, промпт агента обязан предпочитать их
  полнотексту. Полнотекстовый слой — для требований и контекста, не для формул.

## 2026-07-18 — Revit 2026 API в execute_revit_code: три граблины подряд

- **Симптом.** Скрипты через revit-mcp `execute_revit_code` падают:
  `'ElementId' object has no attribute 'IntegerValue'`; «Multiple targets could match»
  на `ElementId(int)`; «Starting a new transaction is not permitted».
- **Причина.** В Revit 2026 у `ElementId` свойство `.Value` (IntegerValue убран);
  конструктор в IronPython требует явного `Int64`; эндпоинт code_execution сам
  оборачивает код в транзакцию — своя `DB.Transaction` вложенная и запрещена.
- **Правило.** id брать как `int(str(element.Id))`, создавать через
  `DB.ElementId(Int64(x))` (`from System import Int64`), транзакции в коде для
  execute_revit_code не открывать.

## 2026-07-18 — pyRevit молча пропускает расширение с default_enabled=False

- **Симптом.** Routes Server отвечает, но маршруты расширения не зарегистрированы:
  `RouteHandlerNotDefinedException` на `/revit_mcp/status/`; ошибок при старте не видно.
- **Причина.** В extension.json у revit-mcp-server стоит `"default_enabled": "False"` —
  pyRevit не грузит такое расширение, пока в pyRevit_config.ini нет явного
  `[<имя>.extension] disabled = false`.
- **Правило.** После копирования стороннего расширения включать его явно:
  `pyrevit configs "<имя>.extension:disabled" disable` — и перезапускать Revit.

## 2026-07-18 — Локальный прокси Autodesk перехватывает запросы к localhost

- **Симптом.** pyRevit Routes Server слушает порт 48884 (видно в netstat), но
  `curl`/`Invoke-WebRequest` к `http://localhost:48884/...` возвращают 503
  «Forwarding failure» от Privoxy.
- **Причина.** Autodesk Genuine Service поднимает локальный прокси Privoxy
  (127.0.0.1:8118) и прописывает его в системные настройки; HTTP-клиенты по
  умолчанию гонят через него даже запросы к localhost.
- **Правило.** Все обращения к локальным API САПР — в обход прокси:
  `curl --noproxy '*' ...`; в Python — `proxies={"http": None}` или
  `NO_PROXY=localhost`. Проверять маршрут запроса до того, как винить сервер.

## 2026-07 — Наивный RAG на строительных нормах не работает

- **Симптом.** Фронтир-LLM «из коробки» массово выдумывают номера пунктов СП
  (~120 выдуманных ссылок на 3000 слепых оценок в эксперименте с Хабра).
- **Причина.** Модель «вспоминает» нормы вместо того, чтобы искать их по базе; таблицы
  и формулы теряются при векторизации PDF.
- **Правило.** Нормы — только через агентный поиск с обязательной цитатой; таблицы и
  формулы — в структурированные правила и расчётный код. Закреплено в
  .claude/rules/norms.md; подробности — docs/01-issledovanie.md §5.
