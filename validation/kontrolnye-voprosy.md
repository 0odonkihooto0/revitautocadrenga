# Контрольные вопросы для проверки базы знаний норм ВК

Набор для валидации этапа 1 (план: docs/03-plan-realizacii.md, критерий — ≥ 90 %
верных ответов с верной цитатой). Ответы «подтверждённых» вопросов перенесены из
текста СП со сверкой по PDF; заготовки заполняются по мере оцифровки документов.

Правила прогона: вопрос задаётся модели с доступом к norms/ и rules/; ответ засчитывается,
если совпали значение и ссылка (документ + пункт/таблица).

## Подтверждённые вопросы (ответ сверен с текстом СП 30.13330.2020)

1. **Каков расход стоков от унитаза со смывным бачком?**
   1,6 л/с. — СП 30.13330.2020, приложение А, таблица А.1, поз. 16.

2. **Минимальный диаметр отводного трубопровода от унитаза?**
   85 мм (условный проход отвода). — СП 30.13330.2020, таблица А.1, поз. 16, 17.

3. **Общий секундный расход воды ванной со смесителем?**
   0,25 л/с (q0_tot); холодной/горячей — по 0,18 л/с. — СП 30.13330.2020, таблица А.1, поз. 6.

4. **По какой формуле определяется максимальный расчётный секундный расход воды?**
   q = 5·q0·α, формула (2). — СП 30.13330.2020, п. 5.3.

5. **Когда коэффициент α берётся по таблице Б.1, а когда по Б.2?**
   Б.1 — при P > 0,1 и N ≤ 200; при других значениях P и N — Б.2.
   — СП 30.13330.2020, п. 5.3.

6. **Чему равен α при N·P менее 0,015?**
   0,200. — СП 30.13330.2020, приложение Б, таблица Б.2.

7. **Как вычисляется вероятность действия приборов при однотипных водопотребителях?**
   P = q_hr,u·U / (q0·N·3600), формула (3). — СП 30.13330.2020, п. 5.4а.

8. **Как определяется расчётный расход стоков для канализационного стояка?**
   qs = q_tot + q0s (общий расход по п. 5.3 плюс максимальный секундный расход стоков
   от прибора с максимальным водоотведением по табл. А.1), формула (5).
   — СП 30.13330.2020, п. 5.5.

9. **Как определяется расчётный расход стоков для горизонтального отводного трубопровода?**
   qsL = q_hr_tot/3,6 + Ks·q0s, формула (7); Ks — по таблице 5.1 в зависимости от N и L.
   — СП 30.13330.2020, п. 5.7.

10. **Какие q0 допускается принимать в жилых и общественных зданиях без данных о приборах?**
    q0_tot = 0,3 л/с; q0_h = q0_c = 0,2 л/с. — СП 30.13330.2020, п. 5.2, примечание 2.

11. **Каково условие самоочищения безнапорного канализационного трубопровода?**
    V·√(h/d) ≥ K, где K = 0,5 для полимерных труб и 0,6 для прочих, формула (33).
    — СП 30.13330.2020, п. 19.1.

12. **Минимальные скорость стоков и наполнение самотёчного трубопровода?**
    V ≥ 0,7 м/с (самоочищающая), наполнение h/d ≥ 0,3. — СП 30.13330.2020, п. 19.1.

13. **С каким уклоном прокладываются нерасчётные участки отводных трубопроводов?**
    1/d — и только если условие (33) невыполнимо, а увеличить число стояков,
    присоединяемых к трубопроводу, невозможно. — СП 30.13330.2020, п. 19.1.

14. **Допускается ли менять уклон сборного отводного (горизонтального) трубопровода?**
    Нет, не допускается. — СП 30.13330.2020, п. 18.2.

15. **Минимальный уклон подвесных отводных трубопроводов внутренних водостоков?**
    0,005; для остальных — по требованиям раздела 19. — СП 30.13330.2020, п. 21.7.

16. **Пропускная способность вентилируемого стояка ПВХ 110 при поэтажном отводе 110 мм
    и угле присоединения 87,5°?**
    3,58 л/с. — СП 30.13330.2020, приложение К, таблица К.1.

17. **Что делать, если расход стоков превышает пропускную способность стояка по прил. К?**
    Увеличить диаметр стояка либо рассредоточить расход по нескольким стоякам.
    — СП 30.13330.2020, п. 19.2.

18. **Максимальная допустимая скорость воды в трубопроводах В1/Т3 по условию шума?**
    1,5 м/с (при коэффициенте местных сопротивлений до 5 — независимо от уровня шума
    и типа арматуры; при бóльших КМС — ниже, по таблице приложения И).
    — СП 30.13330.2020, приложение И.

19. **Максимальная длина выпуска канализации Ду 100 от стояка до оси смотрового колодца?**
    12 м; при большей длине — дополнительный смотровой колодец. Для незагрязнённых
    стоков при Ду ≥ 100 допускается до 20 м. — СП 30.13330.2020, п. 18.36, таблица 18.2.

20. **Допускается ли прокладка стояков бытовой канализации снаружи здания?**
    Нет; также не допускается прокладка в местах, где доступ связан с ослаблением
    несущих конструкций (под фундаментными плитами, в ограждающих конструкциях,
    в конструкции перекрытий). — СП 30.13330.2020, п. 18.38.

21. **Каким принимается диаметр канализационного выпуска?**
    По расчёту, но конструктивно не меньше диаметра наибольшего из присоединяемых
    к выпуску стояков. — СП 30.13330.2020, п. 18.34.

22. **Расчётный расход дождевых вод на водосточный стояк диаметром 100 мм?**
    20 л/с. — СП 30.13330.2020, таблица 21.1.
