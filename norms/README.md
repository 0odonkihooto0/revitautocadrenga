# Полные тексты норм (слой 3 базы знаний)

Markdown-версии нормативных документов ядра ВК (список ядра — docs/01-issledovanie.md §4).
Решение коммитить полные тексты в репозиторий — в docs/decisions.md. Два источника:

- готовая конвертация ФАУ ФЦС (`C:\BazaSnipMD\normative-md`) — СП 30, 73, 31;
- автоконвертация pymupdf из PDF (`C:\SNIPpars\downloads_faufcc\add`, скрипт сессии
  2026-07-18) — СП 32, СП 10, ГОСТ 21.601, ПП 87; колонтитулы вычищены, переносы слов
  склеены, случайные пункты сверены с PDF дословно.

⚠️ Конвертация местами неточна (формулы, разметка таблиц, слипшиеся слова). Числовые
значения для слоя правил (`rules/`) переносить только со сверкой по PDF — правило
.claude/rules/norms.md.
