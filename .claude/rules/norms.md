# Работа с нормативными документами (СП, ГОСТ, СНиП)

Достоверность норм — ядро проекта. Выдуманная ссылка на пункт СП — худшая ошибка в этом
репозитории (обоснование: docs/01-issledovanie.md §5).

- Любое утверждение «норма требует X» сопровождай точной ссылкой: документ, редакция,
  пункт или таблица. Пример: «СП 30.13330.2020, п. 8.7.3, табл. 8.3».
- Не цитируй пункт по памяти. Нет текста документа перед глазами — пиши значение с
  пометкой «⚠️ требует проверки по тексту СП» и не выдавай его за подтверждённое.
- Следи за актуальностью редакций: у СП бывают изменения и замены; при сомнении явно
  укажи, какая редакция имелась в виду.
- Числа не «прикидывай»: расчётные значения (расходы, уклоны, диаметры, напоры) — только
  из таблицы правил, формулы с источником или расчётного кода.
- Ядро нормативной базы ВК перечислено в docs/01-issledovanie.md §4; новые документы
  добавляй в ту же таблицу.
