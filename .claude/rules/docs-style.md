# Стиль документации

- Имена файлов: транслит; тематические документы с номером (`01-issledovanie.md`),
  служебные без номера (`status.md`). Один H1 в начале файла — название документа.
- Строки — примерно до 100 символов, как в существующих документах.
- Перекрёстные ссылки между документами — относительные (`[текст](02-arhitektura.md)`).
- Сравнения и перечни со структурой — таблицами; схемы — mermaid.
- Внешние ссылки — только реально существующие и проверенные; не сочиняй URL.
- Добавил документ в docs/ → добавь строку в таблицу README.md и карту в CLAUDE.md.
- После правок запусти `/check-docs` и почини найденные проблемы.
