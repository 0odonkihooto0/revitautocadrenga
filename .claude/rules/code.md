# Правила кода и структурированных правил норм

Код появляется в проекте с этапов 0–1 (см. docs/03-plan-realizacii.md).

## Python

- Python 3.11+, зависимости через `uv`; аннотации типов у публичных функций.
- Каждая расчётная функция по нормам — docstring со ссылкой на источник (документ,
  пункт, формула), как в примере docs/02-arhitektura.md §4.
- Расчётный код покрывается юнит-тестами по примерам из учебников/пособий; без
  прошедшего теста расчёт не считается готовым.

## YAML-правила норм (слой 1 базы знаний)

- Каждое правило обязано иметь поле `source` с точной ссылкой на документ и
  пункт/таблицу; шаблон — docs/02-arhitektura.md §4.
- Значения в правилах — только перенесённые из текста документа, не по памяти модели
  (см. правило norms.md).
