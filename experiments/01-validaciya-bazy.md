# Эксперимент 01: Первая валидация базы знаний норм ВК

**Дата:** 2026-07-18
**Статус:** завершён
**Этап плана:** этап 1 — база знаний норм ВК (§4 плана: контрольные вопросы)

## Цель

Проверить критерий готовности этапа 1: модель с доступом к базе знаний отвечает
на ≥ 90 % контрольных вопросов верным значением с верной цитатой (документ + пункт).

## Окружение

| Компонент | Детали |
|---|---|
| Модель | Claude Sonnet (`claude -p --model sonnet`), Claude Code CLI 2.1.214 |
| База знаний | norms_mcp: BM25-поиск по 7 документам norms/ (2743 чанка) + YAML-правила rules/ |
| Изоляция | запуск из каталога вне репозитория; инструменты только `mcp__norms__*` (`--strict-mcp-config`); файл с эталонами модели недоступен |
| Вопросы | 30 подтверждённых из validation/kontrolnye-voprosy.md (эталоны сверены с PDF) |

## Ход эксперимента

1. Скрипт прогона (scratchpad) парсит подтверждённые вопросы, каждый уходит отдельным
   `claude -p` с системным промптом «отвечай только по базе, обязательна цитата,
   нет в базе — так и скажи»; 4 параллельных воркера, ответы в JSON.
2. Итерация 1: модели доступен только полнотекстовый слой (search_norms/get_clause).
   Результат 22/30 (73 %) — разбор ошибок в validation/progon-2026-07-18.md.
3. Починка: в norms_mcp добавлены инструменты слоя 1 — list_rules/get_rule (YAML-правила,
   сверенные с PDF); в промпт — предпочтение слоя правил для чисел и формул и приоритет
   СП 30/73 для вопросов о внутренних системах.
4. Итерация 2: перепрогон 8 упавших вопросов — все верно.

## Результат

**30/30 (100 %) после второй итерации — критерий этапа 1 достигнут.**
Таблица итераций и разбор ошибок: [validation/progon-2026-07-18.md](../validation/progon-2026-07-18.md).

Ни одной выдуманной ссылки за обе итерации: на битых местах базы модель честно
пасовала («в базе не найдено»), единственный домысел — угадала знак сравнения там,
где md-конвертация его потеряла (Q5, N ≤ 200).

## Выводы

1. Слой 3 (полнотекстовый поиск) сам по себе не проходит порог: md-конвертация теряет
   формулы и знаки сравнения. Слой 1 (структурированные правила, сверенные с PDF) —
   обязательная часть контура; вместе — 100 %. Урок → docs/lessons.md.
2. Агентный поиск с обязательной цитатой действительно подавляет галлюцинации ссылок
   (0 выдуманных пунктов) — подтверждение вывода исследования §5 на своей базе.
3. Следующий шаг: переформулировать вопросы 11–12 (двусмысленны после добавления
   СП 31/32), расширять базу вопросов по мере оцифровки (заготовки 31–41).
