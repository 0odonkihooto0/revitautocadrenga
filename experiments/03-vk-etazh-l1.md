## Цель

Спроектировать ВК всего этажа L1 по **чистой АР-модели** (без MEP-коннекторов и стояков),
оформить лист «план + спецификация + марки» и закрыть пункты status.md: чек-лист v1,
проба сабагента-нормоконтролёра, фитинги, учёт стен, clash detection.

## Ход эксперимента

1. **Аналитик v0.1.** На плане L1 — 40 санприборов: 5 типовых санузлов (2 подвесных
   унитаза + 2 умывальника + 2 трапа) в трёх блоках с разными отметками полов и
   производственная кухня (мойки общепита, инвентарная, рукомойник, 3 напольных трапа,
   арматура). Кластеризация по регионам, маппинг семейств на табл. А.1
   (Toilet-Commercial-Wall → унитаз со смывным краном — допущение). Ключевая новация:
   у АР-семейств нет коннекторов — **точки подключения синтезированы по нормам**
   (calc/trace/connectors.py: высоты СП 73 п. 6.2.1, диаметры табл. А.1, конструктивные
   допущения помечены). Паспорт: 6 кластеров, 37 приборов, стояки у стен-хостов/в шахтах
   Chase ([build_passport.py](03-vk-etazh-l1/build_passport.py)).
2. **Расчётчик v0.1.** Пер-кластерная гидравлика: В1 санузла 2,043 л/с → Ду50
   (смывные краны дают большой q0 = 1,4), Т3 0,18 → Ду15; кухня В1/Т3 → Ду25. Подбор
   стояка К1 по прил. К (новый pick_stack_dn): Ду110, qs = 3,443 ≤ 3,58 л/с — впритык.
   Подводка смывного крана подобрана по скорости (Ду40) — табл. А.1 её не нормирует.
3. **Трассировщик v0.1.** Оси трасс вдоль стен кластера (axis x/y, транспонирование),
   лучи коллектора/магистрали в обе стороны от стояка (фикс: только в стороны с
   приборами), вертикальные стояки К1. 185 сегментов, `uv run python
   experiments/03-vk-etazh-l1/run_pipeline.py`.
4. **Чек-лист v1** (+3 проверки): отвод ≥ выпуска прибора (закрыта грабля эксп. 02),
   высоты арматуры по СП 73 (800 ± 20 мм), Hтр по ф. (14) = 26,4 м (i по Дарси–Вейсбаху,
   гарантированный напор — задание инженера). **193 проверки, 0 нарушений**; 98 тестов.
5. **Создание в Revit.** В АР-модели один PipeType «Default» с имперским каталогом —
   Ду СП мапится на ближайший размер (110→101,6 и т.д.). 185 труб созданы по кластерам,
   верифицированы чтением обратно (системы/диаметры/геометрия/уклон 0,0200 — всё верно).
   Модель-сэмпл оказалась **read-only** — Save As в models/ (вне git), см. lessons.
6. **Фитинги (стретч).** Семейств фитингов в АР-модели ноль; загружен M_Elbow - Generic
   из библиотеки, правило Elbows добавлено в RoutingPreferences. **90 отводов** на
   поворотах равного диаметра; 15 узлов «магистраль→ответвление» с переходом диаметра
   не соединить отводом (нужны тройники/редукторы — v1), тройники не создавались.
7. **Лист ВК-1** «План этажа L1. Водоснабжение и канализация»: дубль плана L1
   (дисциплина Coordination, Medium — трубы однолинейные, толщина 6, view range от
   коллекторов до магистралей), спецификация труб с итогами по типоразмерам
   (В1 82,1 м + Т3 48,2 м + К1 85,6 м = **215,9 м**), 37 марок магистралей/стояков.
   Скриншот: [list-vk-1.png](03-vk-etazh-l1/list-vk-1.png).
8. **Clash detection (стретч).** 200 пар: 167 со стенами (систематика допущения
   «подключения на оси стены» + промах: коллектор кухни сквозь вторую стену двойной
   конструкции), 33 с перекрытиями (проходки без гильз, коллектор в толще плиты) —
   [clash_report.json](03-vk-etazh-l1/clash_report.json).
9. **Нормоконтроль сабагентом (стретч).** Первая боевая проба `normokontroler`:
   4 нарушения, которых чек-лист не видит (90°-переход стояка в коллектор — п. 18.4/18.5;
   стояки без вытяжной части — п. 18.18/18.22, причём как невентилируемые по табл. К.8
   они **не проходят** по расходу; мойки общепита без разрыва струи — п. 18.12; Ду110
   в стенах 79–108 мм физически не помещается — СП 73 прил. А) + 4 условных замечания —
   [normokontrol.md](03-vk-etazh-l1/normokontrol.md).

## Результат

Полный контур на этаж: АР-модель → паспорт (6 кластеров) → расчёт → 185 сегментов →
трубы+фитинги в Revit → лист ВК-1 со спецификацией и марками → clash-отчёт →
нормоконтроль с цитатами. Чек-лист зелёный; сабагент нашёл 4 реальных нарушения уровня
инженерных решений — ровно та растущая роль, под которую он создавался.

Грабли по пути (подробно — docs/lessons.md): кириллица в execute_revit_code и
MCP-параметрах приходит latin-1-мохибейком; после LoadFamily/AddRule нужен Regenerate;
вставка отвода инвалидирует соседние коннекторы; сэмпл-модель read-only — работа
теряется без Save As; «≤» роняет вывод в cp1251-консоли.

## Ограничения v0.1 (осознанные)

- Тройники, редукторы и врезки не создаются (только отводы равных диаметров);
  сегменты в узлах «магистраль→ответвление» и «выпуск→коллектор» не соединены.
- Приборы не подключены к трубам (у АР-семейств нет коннекторов — принципиально).
- Нарушения нормоконтроля №1–4 в модели не исправлены — задачи трассировщику v1.
- Марки — имперские («4"ø»), диаметры листа в дюймах: каталог и шаблоны семейств
  имперские, русских аннотаций в модели нет.
- U и q_hr_u — демо-значения (табл. А.2 не оцифрована); позиции стояков — допущение.

## Выводы

   слой правил (СП 73 + табл. А.1) оказался достаточной опорой; решение → decisions.
2. Сабагент-нормоконтролёр даёт другой класс находок, чем rule-based чек-лист:

   Связка «чек-лист для чисел + сабагент для требований» — рабочая архитектура контура.
