# Журнал экспериментов

Здесь фиксируются практические эксперименты проекта (этап 0 и далее): проба MCP-серверов,
подключение к Renga через COM, прогоны команд на учебных моделях.

## Правила ведения

- Один эксперимент — один файл `NN-nazvanie.md` (номера по порядку, первый — 00).
- Создавать через skill `/new-experiment <название>` — он использует шаблон
  `.claude/skills/new-experiment/template.md` и сам подставит следующий номер.
- Фиксировать честно: что сработало, что нет, точные команды и версии; скриншоты —
  в папку `NN-nazvanie/` рядом с файлом.
- Итог эксперимента — 2–3 вывода и следующий шаг; заметное открытие → docs/lessons.md
  или docs/decisions.md, продвижение → docs/status.md.
